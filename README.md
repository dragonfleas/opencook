# OpenCook

OpenCook is an open-source retail automation bot designed to level the playing field against scalpers and give everyone a fair shot at products they're passionate about. Whether you're a collector attempting to pull that chase card, a gamer trying to snag a graphics card at MSRP, or a parent desperately seeking to see a smile on your child's face this christmas, OpenCook is your ally against the bots that have ruined online shopping. The current retail landscape is broken. Scalpers use sophisticated bots that they pay large amounts of money for, to instantly buy up entire inventories of high-demand products, only to resell them at massive markups. We believe this is fundamentally wrong.

The name is on the nose on purpose, we _hate_ scalpers. If this software results in retail stores having better bot detection, great, that's still a win for us because it compromises closed source automation tools. Yes, you can use this software to buy a ton of product, but if _everyone_ has access to it, then the optimization will have to be at the setup level, we think that's a more fair chance than iPhone Joe competing with "cook groups" that have thousands of bots, addresses, payment info, & emails all blasting endpoints and either taking ALL of the product instantly, or taking the site down...and subsequently still taking all the product and wasting more time of others.

## Installing OpenCook

> [!WARNING]
> OpenCook is currently _very_ early in development and is subject to substantial breaking changes. Use at your own risk.

You can download our binaries from the [releases](https://github.com/dragonfleas/opencook/releases) page, our supported operating systems are Windows, MacOS, and Linux 64-bit.

## Project Setup

### Install

```bash
$ npm install
```

### Development

```bash
$ npm run dev
```

### Build

```bash
# For windows
$ npm run build:win

# For macOS
$ npm run build:mac

# For Linux
$ npm run build:linux
```
